# תצוגת זיס לבדיקה

[אינדקס מרכזי](../../PLAN_INDEX.md) · [ממצאים והמלצות](../../docs/planning/VISUAL_REVIEW.md).
נוצרה ונבדקה ב־22–23.09.2026. מיועדת לסקירת עיצוב; אינה חנות פעילה או סביבת סליקה.

## קבצים

- `source-original.html`: עותק מוכן לעיון של Lis Patisserie.html החיצוני; נשמר ללא שינוי.
- `source-standalone.html`: עותק גרסת המקור הנוספת, ללא שינוי.
- `assets/zis-logo-dark.png` ו־`assets/zis-logo-light.png`: קובצי זיס המקוריים עם שקיפות.
- `index.html`: עותק שנוצר עם הלוגו, מיתוג ותיקוני טקסט מוסכמים.
- `review.css`: תיקון גלישה אופקית וגודל הלוגו, בנפרד מעיצוב המקור.
- `screenshots/`: צילומי לפני/אחרי ותוצאות דפדפן. `share/`: עותקים שהוכנו לשיתוף באמצעות סקריפט הבטיחות.

מקור התצוגה והנכסים: תיקיית ליס החיצונית המופיעה באינדקס. לא שונו קובצי המקור החיצוניים.
השינוי הארוז מיועד לבדיקה זמנית; אין להשתמש בו כתחליף לפרויקט הרכיבים המתוכנן.

## הפעלה מקומית משורש המאגר

```powershell
python scripts/build-zis-preview.py
python -m http.server 8765 --bind 127.0.0.1 --directory prototypes/zis-review
```

פותחים [תצוגה מקומית](http://127.0.0.1:8765/index.html). השירות מגיש רק את תיקיית התצוגה ונגיש מהמחשב המקומי. הכתובת פועלת כל עוד השרת רץ; זו אינה פריסה לאינטרנט.

## שחזור בדיקת הדפדפן

נדרשים Node, התקנת playwright-core ודפדפן Chromium של Playwright. משתמשים בהתקנה קיימת ולא מתקינים תלות חדשה רק בשביל צילום.

```powershell
$env:PLAYWRIGHT_MODULE_PATH = 'C:\path\to\node_modules\playwright-core'
node scripts/review-zis-preview.mjs index.html zis
```

הסקריפט מצלם ברוחבי 320, 390, 768 ו־1440, בודק גלישה אופקית, טעינת לוגו/תמונות, שגיאות JavaScript ותפריט נייד. קוד יציאה שאינו אפס מציין כשל. זה אינו מבחן לתשלום אמיתי או לאבטחת יישום היעד.

תוכן Demo עדיין כולל מחירים, פרטי קשר וטענות עסקיות שלא אושרו. אין לבצע דרכו רכישה אמיתית. התאמה מלאה ל־guidelines נדרשת בשלב בניית היישומים, ולא נטענת עבור המקור הארוז.
