# תצוגת זיס לבדיקה

[אינדקס מרכזי](../../PLAN_INDEX.md) · [ממצאים והמלצות](../../docs/planning/VISUAL_REVIEW.md).
נבנתה מחדש ונבדקה ב־24.09.2026 מתוך `Lis-standalone.html` בלבד. מיועדת לסקירת עיצוב; אינה חנות פעילה או סביבת סליקה.

## קבצים

- `source-standalone.html`: עותק המקור החזותי היחיד, ללא שינוי.
- `assets/zis-logo-dark.png` ו־`assets/zis-logo-light.png`: קובצי זיס המקוריים עם שקיפות.
- `assets/standalone-*.jpg`: תמונות המחשה שחולצו מהמקור הארוז כדי לתקן תמונות שבורות בתצוגה. הן אינן Storage חי.
- `index.html`: עותק שנוצר מהמקור היחיד עם לוגו זיס, אזור קטלוג יחיד, גלריית אירועים ומקטעים לא נחוצים שהוסרו.
- `review.css`: תיקוני פריסה, מסגרות, כרטיסים וגלריה בנפרד מעיצוב המקור.
- `screenshots/zis-standalone-*`: צילומי בדיקה ותוצאות דפדפן. `share/`: עותקים שהוכנו לשיתוף באמצעות סקריפט הבטיחות.

מקור התצוגה והנכסים: תיקיית ליס החיצונית המופיעה באינדקס. לא שונו קובצי המקור החיצוניים.
השינוי הארוז מיועד לבדיקה זמנית; אין להשתמש בו כתחליף לפרויקט הרכיבים המתוכנן.

## הפעלה מקומית משורש המאגר

```powershell
python scripts/build-zis-preview.py
python -m http.server 8765 --bind 127.0.0.1 --directory prototypes/zis-review
```

פותחים [תצוגה מקומית](http://127.0.0.1:8765/index.html). השירות מגיש רק את תיקיית התצוגה ונגיש מהמחשב המקומי. הכתובת פועלת כל עוד השרת רץ; זו אינה פריסה לאינטרנט.

## שחזור בדיקת הדפדפן

נדרשים Node, התקנת playwright-core ודפדפן Chromium של Playwright. משתמשים בהתקנה קיימת ולא מתקינים תלות חדשה רק בשביל צילום.

```powershell
$env:PLAYWRIGHT_MODULE_PATH = 'C:\path\to\node_modules\playwright-core'
node scripts/review-zis-preview.mjs
```

הסקריפט מצלם ברוחבי 320, 390, 768 ו־1440, בודק גלישה אופקית, טעינת לוגו/תמונות, שגיאות JavaScript ופעולת גלריית האירועים. קוד יציאה שאינו אפס מציין כשל. זה אינו מבחן לתשלום אמיתי או לאבטחת יישום היעד.

תוכן Demo עדיין כולל מחירים ומוצרים שלא אושרו; פעולות רכישה מדומות הוסרו מן המסך. מוצרים, ערים, מחירים ותמונות יגיעו מה־DB ומ־Storage דרך API רק לאחר בניית היישומים. [כללי התוכן והפערים](../../docs/planning/STORE_CONTENT_AND_GALLERY.md). אין לבצע דרך ההמחשה רכישה אמיתית. התאמה מלאה ל־guidelines נדרשת בשלב בניית היישומים.
