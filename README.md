# ZIS — חנות מקוונת למוצרי Sets

**מתחילים ב־[אינדקס המרכזי](PLAN_INDEX.md)**: כל המסמכים, תפקידם, מצבם וקישורים להמשך העבודה.

המטרה היא חנות מלאה: קטלוג ותמונות מנתונים אמיתיים, דפי מוצר ווריאציות, עגלה, רכישה כאורח, תשלום, ניהול מוצרים, הכנת הזמנות ומשלוחים.

## מצב מאומת — 18.09.2026

- קיימים `zis-api` עם Express/TypeScript ומימוש חלקי של מלאי ואימות מנהלים, ו־`zis-db` עם ארבע מיגרציות.
- שני קובצי HTML של ליס נמצאו בתיקיית המקור החיצונית ונבדק הקוד הארוז בהם. הם אב־טיפוס עם נתוני הדגמה ואישור הזמנה מדומה.
- אין במאגר אפליקציות Storefront/Admin עצמאיות, API לקטלוג/תמונות, Checkout או סליקה מלאה.
- מצב מסד חי, Storage וספקי שירות לא אומת; אין לראות בקובצי מיגרציה הוכחה שהם הופעלו.
- TypeScript עבר בסקירה. `npm.cmd test` נעצר ב־`uv_os_get_passwd / ENOMEM` לפני טעינת הבדיקות. אין סקריפט Lint.

הראיות והגבולות מפורטים ב־[דוח הסקירה](docs/SYSTEM_AUDIT.md).
