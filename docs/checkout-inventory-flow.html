07 · SQL של Availability

המלאי הפשוט מומר ל־Sets; וריאציה כבר ב־Sets

-- מוצר פשוט: מחיר Set וזמינות Sets שלמים
select p.product_id, null::uuid as product_variant_id,
       (p.price_per_item * p.set_size)::text as price_per_set,
       (p.available_items / p.set_size) as available_sets
from public.products p
join public.categories c on c.category_id=p.category_id
where p.product_id=any($1::uuid[])
  and p.status='active' and not p.is_deleted
  and c.status='active' and not c.is_deleted
  and not exists(select 1 from public.product_variants v
                 where v.product_id=p.product_id and not v.is_deleted)
  and exists(select 1 from public.product_images i
             where i.product_id=p.product_id and i.product_variant_id is null
               and i.image_type='primary' and not i.is_deleted)
union all
-- וריאציה: available_sets נשאר ישיר
select p.product_id, v.product_variant_id,
       (v.price_per_item * p.set_size)::text, v.available_sets
from public.product_variants v
join public.products p on p.product_id=v.product_id
join public.categories c on c.category_id=p.category_id
where v.product_variant_id=any($2::uuid[])
  and v.status='active' and not v.is_deleted
  and p.status='active' and not p.is_deleted
  and c.status='active' and not c.is_deleted;

אחרי SQL: השרת מצמיד לפי productId + variantId. פריט שלא חזר מהשאילתה מקבל availableSets=0. חוסר = max(requestedSets − availableSets, 0).

13 · דוגמת יחידות ומעבר לתפעול

מוצר פשוט: 23 יחידות פירושן 3 Sets למכירה

23 יחידות ÷ 6 לסט = 3 Sets מלאים

אם אושרו 2 Sets, ההפחתה היא 12 יחידות. יתרה חדשה: 11 יחידות, כלומר Set אחד זמין ועוד 5 יחידות שלא יוצרות Set.

וריאציה: 3 Sets − 2 Sets = 1 Set

מלאי וריאציה והיסטוריית התנועה נמדדים ב־Sets. מלאי מוצר פשוט ותנועתו נמדדים ביחידות פיזיות.

אחרי paid: תהליך Admin

Dashboard/Orders קוראים הזמנות לפי delivery_date. רשימת הייצור כוללת paid בסטטוס ordered או in_preparation ומסכמת quantity_sets. סטטוס מתקדם ordered → in_preparation → packed → in_transit → delivered → approved. המעבר הראשון דורש payment_status=paid; נהג משלוחים יכול רק in_transit → delivered.
