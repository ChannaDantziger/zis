- נוסף מעבר מכל וריאציה להזמנות שלה לפי תאריך; הוא מנקה מסננים ובחירה קודמים. אין נתוני ייצור בתאריכים שנבדקו, ולכן מעבר זה ופרטי הזמנה ממתינים לאימות עם נתונים.

## הגדרות חסרות — 09.10.2026

בדיקת SQL שביצעה בעלת האתר החזירה configured=false לרשומת store_settings עם מזהה 1. זהו הגורם המזוהה לשגיאה בקוד טעינת ההגדרות. הוכן [תיקון ממוקד](../zis-db/migrations/009_initialize_store_settings.sql), שלא הורץ בידי הסוכן, והוספה שגיאת 503 STORE_SETTINGS_NOT_CONFIGURED. API build ותשע בדיקות יחידה עברו; לאחר דיווח בעלת האתר שהריצה 009, רענון /settings עם session קיים הציג את טופסי ההגדרות ללא השגיאה; החנות סגורה (store_open=false, lock_mode=closed). טעינת המסך אומתה ב־09.10.2026; פעולות שמירה לא נבדקו ולא שונו נתונים.

## תקלה בהגדרות משלוח — 09.10.2026

בבדיקת הדפדפן הראשונית עם session קיים, `/settings` הציג `An unexpected error occurred`. בהמשך זוהתה רשומת הגדרות חסרה; לאחר דיווח על הרצת 009 טעינת המסך אומתה, כמתועד לעיל. התבקש `diagnosticCode` מהלוג עבור `/admin/commerce/settings` בלבד, ללא סודות. נשמרה בדיקה בקריאה בלבד; לא שונו הגדרות או נתונים ולא הופעלו מיגרציות.

## עימוד הזמנות — 09.10.2026

בעלת האתר דיווחה שהמסכים נטענים לאחר תיקון החיבור עם Session pooler. בקוד נוספו מסנן וריאציה ועימוד בשרת; API build, Admin typecheck ו־13 בדיקות ממוקדות עברו. בדפדפן נראה המסנן החדש, אך ה־API הפעיל עדיין מחזיר orderId must be a UUID לנתיב החדש, ולכן נדרשת הפעלה מחדש לפני המשך האימות. Vite build חסום ב־EPERM. [מימוש, חוזים וגבולות](ADMIN_ORDERS.md).

## המשך אבחון — 09.10.2026

לוג שסופק עבור `/admin/dashboard` מכיל שגיאה כללית ללא `diagnosticCode`. עדכון האבחון מציג תמיד קוד מוכר או `UNCLASSIFIED` ומזהה קודים מתוך שגיאות עטופות; הבנייה ושש בדיקות יחידה עברו. יש להפעיל מחדש את שרת ה־API באותה פקודה וסביבה, לרענן ולבדוק את הקוד בלוג. התקלה במסכי הנתונים טרם תוקנה או אומתה מחדש.

## בדיקה עם session קיים — 08.10.2026

נפתח האתר המקומי של בעלת האתר ב־localhost:5173: משתמש מחובר וניווט מוגן נראים, אך Dashboard, Orders ו־Tasks נכשלו בטעינת נתונים עם `An unexpected error occurred`. לא נבדקו פעולות כתיבה. אין להסיק מכך שהסכמה או מסכי הנתונים אומתו.

הוספנו `diagnosticCode` מסונן בלוג השרת בלבד; אין הדפסה של הודעת תשתית גולמית, SQL, token או כתובת חיבור. נדרש הקוד מהטרמינל שמריץ API אחרי רענון כדי להמשיך באיתור הגורם. בדיקת `/health/ready` הישירה נחסמה בדפדפן. בדיקות HTTP המקומיות נחסמו ב־EACCES גם לאחר בקשת הרשאה; זהו חסם בדיקות נפרד מתקלה האתר, ואין טענה שזו סיבת התקלה.

## המשך 08.10 — הזמנות ופרטים

עדכון משימות בהמשך אותו יום: נוספו יצירה, עימוד וסגירה ידנית, API עם הרשאות ו־Audit, וספירת כלל המשימות הפתוחות בדשבורד. API build ו־Admin typecheck/build עברו; 51 בדיקות עברו, 0 נכשלו ובדיקת DB אחת דולגה. ראו [תיעוד המשימות](ADMIN_TASKS.md) לגבולות המימוש. UI מחובר ו־DB נשארים לאימות בסוף הבנייה.

לפי הוראת בעלת האתר ממשיכים בבנייה ובבדיקות מקומיות. אימות הגישה ל־DB ול־Production נדחה לסוף הבנייה; היעדר כתובת חיה אינו חסם להמשך הקוד.

- מסך הזמנות: תאריך אספקה, חזרה להיום, סינון עיר, מיון סטטוס/מוצר/עיר/מספר/סכום וכיוון המיון. שינוי תאריך/מסנן מנקה בחירה.
- בחירה מרוכזת: סימון הזמנות שניתן לקדם בלבד ופעולה זמינה כאשר יש מעבר הבא משותף. השרת ממשיך לאמת גרסה, תשלום והרשאה לכל שורה.
- פרטי הזמנה: נתיב `/orders/:orderId` עם פריטים, לקוחה, כתובת, אולם, הקדשה, הערות, משימות פתוחות והיסטוריה. שינוי פרטני משתמש ב־`bulk-status` עם שורה אחת; יש קישור לייצור היום.
- API פרטים: `GET /admin/orders/:orderId`, למנהל תפעול פעיל בלבד. זהות ללא תפקיד ומשלוחן נדחים לפני שליפה. כתובת מוחזרת לפי רשימת שדות מותרת; cache HTTP מבוטל ומטמון פרטים מוסר לאחר יציאה מהמסך.
- תאריך שלא קיים בלוח השנה נדחה. הצעת הכנה ניתנת רק לאחר `paid`. שאילתת ההזמנות משתמשת בטקסט לאיגוד מזהי UUID, מחזירה תאריך ISO וממיינת לפי שלב תפעולי.
- הדשבורד מציג תוויות סטטוס בעברית וספירות מהשרת; מונה ביטולים מופיע רק מעל אפס. בייצור הוסר Progress של 100% שלא התבסס על התקדמות אמיתית.

אימות מקומי עדכני: TypeScript ובנייה עברו בשני הפרויקטים; 34 בדיקות API מקומרות עברו, ללא כשל ובדיקת DB אחת שדולגה. בדיקות חדשות מכסות הצעת הכנה רק לאחר תשלום, פרמטרי סינון, שחרור client בכשל, תאריך לא תקין, הגנת פרטים לפי זהות/תפקיד, UUID, 404 ו־no-store. הבנייה המקומית ללא קובצי סביבה אינה מיועדת לפריסה.

בדיקת דפדפן נוספת: פתיחת קישור ישיר לפרטי הזמנה ללא session הפנתה ל־Login. בחירת שורות מתנקה ביציאה ובהתחברות כדי שלא לעבור בין משתמשים. המסכים לאחר Login עדיין לא אומתו בדפדפן.

השלמות: מסנן מוצר/וריאציה ועימוד הזמנות, תהליכי משימות מערכת, תמונות בפרטים, PDF, Push וביטול מלא. משימות ידניות וסגירתן קיימות בקוד. בדיקות SQL מול הסכמה החיה ו־UI מחובר עדיין פתוחות; אין סימון P7 כגמור.

## תיקוני קוד שבוצעו

- תוקן `vite-env.d.ts`: הצהרת טיפוס למשתנה ה־API במקום שורת הגדרת סביבה שאינה TypeScript חוקי.
- תוקנו טיפוסי טופס כלל משלוח. ערך עליון `null` נשאר ללא הגבלה בעת שמירת כלל, במקום להיהפך ל־0.
- נוסף תפריט ניווט לנייד עם Burger וסגירה לאחר בחירת מסך.
- תשובת 401 מ־Admin מנקה את ה־session הנוכחי ומפנה לכניסה. תשובת 401 מבקשת Login אינה מוחקת session; תשובה ישנה אינה מוחקת token חדש.
- נתוני React Query מנוקים בעת יציאה והתחברות מחדש, וכן כאשר המסך המוגן מזהה שאין session.
- הודעת שינוי סטטוס נשארת מחוץ לפס הבחירה גם לאחר הצלחה. מוצגות שגיאות בקשה ותוצאות כשל לכל הזמנה; שורות שנכשלו נשארות מסומנות.
- שינוי מסנן סטטוס מנקה בחירה; סימון חוזר אינו יוצר מזהים כפולים.
- עודכנו בדיקות CORS להתנהגות הקיימת ובדיקות Dashboard לשגיאות validation סינכרוניות.

|---|---|---|
| Admin `npm.cmd run typecheck` | עבר | טיפוסים בלבד |
| API `npm.cmd run typecheck` ו־build | עברו | אינם מאמתים DB |

| דפדפן מול הבנייה המקומית | Login נטען; `/orders` ללא session מפנה ל־`/login` | מסכים מחוברים טרם נבדקו |

`npm test` המקורי עדיין נעצר ב־tsx עקב `uv_os_get_passwd / ENOMEM`, גם בניסיון מחוץ להגבלה.
הבדיקות המקומרות הורצו כך מתוך `zis-api`:

```powershell
npm.cmd run build
if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }
$env:RUN_DB_INTEGRATION = 'false'
$tests = @(Get-ChildItem -LiteralPath dist -Filter '*.test.js' -Recurse | ForEach-Object { $_.FullName })
node --test @tests
```

הבנייה הרגילה של Admin נחסמה ב־esbuild בגישה לתיקיית אב, גם בניסיון מחוץ להגבלה.
לצורך אימות מקומי בלבד, מתוך `apps/admin-mobile`, הורצה בנייה ללא קריאת קובצי סביבה:

```powershell
node --input-type=module -e "import { build } from 'vite'; await build({ configLoader: 'native', envDir: false });"
```

Vite התריע על bundle מעל 500 kB. אין עדיין הגדרת Lint בפרויקטים; אין טענה ש־Lint עבר.
שרת Vite Development נחסם באופטימיזציית תלויות; בדיקת הדפדפן השתמשה בבנייה המקומרת.
הפעלת שרת fixtures מקומי לא אושרה, ולכן לא בוצעו בדיקות מסכים לאחר Login או תוצאות שינוי סטטוס בדפדפן.
