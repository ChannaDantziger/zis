## מתי מתעדים

- במהלך הפיתוח מעדכנים החלטות, חוזים, משימות ותוצאות בדיקה.
- בסוף כל יכולת שנבדקה כותבים את תיעוד המימוש האמיתי ומגבלותיו.
- בסוף הבנייה מבצעים מסירת תיעוד מלאה לפי [P9](IMPLEMENTATION_PLAN.md) ו־[תוכנית התיעוד](planning/DELIVERY_AND_DOCUMENTATION.md).
- אין ליצור מדריכי הרצה מדומים או קישורים לקובצי מסירה שטרם קיימים.

## כללי תחזוקה

עד 320 שורות למסמך. פיצול לפי אחריות, קישור לכל חלק מהאינדקס הראשי ותאריך אימות. אין סודות או פרטי לקוחות אמיתיים. תיעוד חייב להבדיל בין קיים בקוד, נבדק מקומית, נבדק מול שירות חיצוני ומתוכנן.
