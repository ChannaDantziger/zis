### מה המשמעות של “להעלות לדוקר”

- הפיתוח מכין ובודק את אריזת היישום כ־Docker image ואת פקודות ההרצה.
- את מאשרת את מקום האירוח ואת החשבון/העלות. Docker Hub נחוץ רק אם בוחרים בו כ־registry; אינו דרישה אוטומטית.
- התקנת Docker Desktop במחשב שלך נדרשת רק אם תרצי להריץ containers מקומית. אם יידרש אישור התקנה במחשב, הוא יטופל בזמן ההקמה.
- לאחר שיש image שנבדק, מעלים ל־registry/שירות האירוח שנבחר, מגדירים secrets במערכת האירוח ובודקים Staging.
- המעבר לאתר חי נעשה לאחר בדיקות ואישור השקה שלך. המפתח מבצע את ההכנה הטכנית ואת הפריסה המוסכמת.
