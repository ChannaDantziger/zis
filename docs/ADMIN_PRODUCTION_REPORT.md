# רשימת ייצור להדפסה ולשמירה כ־PDF

[אינדקס](PLAN_INDEX.md) · [אימות Admin](ADMIN_VERIFICATION.md) · [דרישות תפעול](planning/OPERATIONS_DELIVERY_PLAN.md).

עודכן: 09.10.2026. המימוש קיים; תצוגה ריקה אומתה בדפדפן, ופתיחת חלון ההדפסה אושרה בידי בעלת האתר. קובץ PDF שמור ורשימה עם נתונים טרם נבדקו.

## שימוש

1. פותחים ייצור ובוחרים תאריך.
2. לוחצים על רשימה להדפסה / PDF. המסך המוגן `/production/print?date=YYYY-MM-DD` שולף נתונים מחדש מה־API.
3. בודקים את תאריך הרשימה ואת זמן השליפה בשעון ישראל. ניתן לרענן לפני הדפסה נוספת.
4. לוחצים הדפסה / שמירה כ־PDF, ובחלון ההדפסה בוחרים מדפסת או שמירה כ־PDF.
5. חוזרים למסך הייצור באמצעות הקישור שבמסך.

אין הדפסה אוטומטית בעת פתיחה, ואין שינוי סטטוס או נתוני מסד. הנתיב נשאר תחת ההגנה הקיימת של מסכי Admin; השרת ממשיך לאמת את המשתמש ואת התאריך.

## תוכן הרשימה

- שם ZIS, תאריך יום הייצור וזמן שליפה בשעון ישראל.
- מספר ההזמנות הפעילות ליום, מספר הווריאציות להכנה וסכום Sets נדרש.
- טבלה: מוצר, וריאציה, Sets, מספר הזמנות לווריאציה וחיווי משימה פתוחה.
- מצב ריק מפורש כשאין ייצור נדרש.

מספר ההזמנות היומי כולל את כלל ההזמנות הפעילות; הייצור הוא תת־קבוצה לפי כללי השרת הקיימים. הזמנה עם כמה וריאציות נספרת בכל שורה מתאימה, ולכן אין לחבר את ספירות ההזמנות בטבלה.

הנתונים נלקחים מ־`GET /admin/dashboard?date=...`, כולל מערך production. אין סיכום מקומי של הזמנות מעמוד בודד. זמן השליפה הוא מועד קבלת התשובה בדפדפן; אין כאן גרסת מסמך שמורה או טרנזקציית דוח חדשה.

## פריסה והגנות

- רכיבי Mantine וטקסט React; שמות מוצרים אינם מוזרקים כ־HTML.
- בזמן טעינה, רענון או שגיאה, כפתור ההדפסה מושבת.
- CSS להדפסה מגדיר A4, מסתיר ניווט וכפתורים, מאפשר שבירת שמות ארוכים ומבקש חזרת כותרות טבלה והימנעות מחיתוך שורה.
- כותרת הדפדפן מכילה ZIS-production ותאריך, ומשוחזרת לאחר יציאה מהמסך.
- רענון אוטומטי במעבר פוקוס מושבת בדוח; רענון מפורש מעדכן את זמן השליפה.
