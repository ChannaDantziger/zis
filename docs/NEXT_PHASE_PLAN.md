# מה עושים עכשיו

[אינדקס](PLAN_INDEX.md) · [תוכנית ראשית](IMPLEMENTATION_PLAN.md) · [מצב מימוש](IMPLEMENTATION_PROGRESS.md) · [נושאים פתוחים](OPEN_ISSUES.md) · [החלטות בעלת האתר](OWNER_ACTIONS.md).

עודכן ב־18.11.2026 כמסמך ניווט. סדר ביצוע נקבע לפי בקשת בעלת האתר העדכנית והתוכנית הראשית; אין להסיק שהעבודה הושלמה מקיומו של מסמך זה. פירוט בדיקות ומגבלות מופיע במצב המימוש ובמסמכי הנושא.

- לשינויים שוטפים: להתחיל באינדקס ובמסמך הנושא ולבדוק את הקוד ומצב העבודה בפועל.
- לטיפול בממצאי הסקירה: לקרוא את [סקירת המערכת](ARCHITECTURE_REVIEW_2026-11-18.md) ואת [הבדיקה הפנימית](ARCHITECTURE_INTERNAL_REVIEW_2026-11-18.md), כולל העדכונים המאוחרים בראש הממצאים.
- למסלולי הזמנה ותשלום: לקרוא את [Checkout](STOREFRONT_CHECKOUT.md), [יצירת הזמנה](ORDER_CREATION.md) וההחלטות הפתוחות. תשלום ניסוי אינו מעיד על סליקה אמיתית.
- לפני פריסה או מסירה: לקרוא את [תוכנית הפריסה](PRODUCTION_DEPLOYMENT_PLAN.md) ואת מצב ההתקדמות, ולהבחין בין בדיקות מקומיות לבין מצב חיצוני שלא אומת.

[הגרסה ההיסטורית](OLD/NEXT_PHASE_PLAN_2026-11-17.md) נשמרת כרקע בלבד ואינה תור עבודה פעיל.
