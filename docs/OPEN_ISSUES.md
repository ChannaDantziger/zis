1. **מוצר פשוט/מורכב:** קוד API, storefront, cart ו־order תומך במוצר פשוט עם מחיר/מלאי ברמת מוצר ובמוצר מורכב עם בחירת וריאציה. מוצר פעיל דורש תמונת מוצר; וריאציה פעילה דורשת תמונה.
2. **תמונות והעלאות:** תמונות מוצר/וריאציה מופרדות מגלריה כללית. יעד upload קובע bucket; נוספה גלריית Admin עם הפעלה וכיבוי.

## ממצא חיבור — 09.10.2026
