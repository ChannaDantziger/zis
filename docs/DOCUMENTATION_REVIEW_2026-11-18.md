## ממצאים להמשך

- תוכנית תיקון הארכיטקטורה שהוצגה בשיחה כ־`ARCHITECTURE_REMEDIATION_PLAN_2026-11-18.md` אינה קיימת כרגע; לא ידועה סיבת היעדרה. ממצאי המקור והעדכונים נשארו ב[סקירה](ARCHITECTURE_REVIEW_2026-11-18.md) וב[סקירה הפנימית](ARCHITECTURE_INTERNAL_REVIEW_2026-11-18.md). נדרש לאחד תוכנית נוכחית מול העבודה שבוצעה מאז.
- האינדקס תיאר את תוצאות התשלום ההיסטוריות כאילו תיקון טרם שולב, למרות עדכון ב[פעולות בעלת האתר](OWNER_ACTIONS.md); תיאור האינדקס תוקן תוך שימור הדוח ההיסטורי.
- [Checkout](STOREFRONT_CHECKOUT.md) מציג ניקוי סל אחרי קריאת אישור, בעוד שבקוד הנוכחי הניקוי מותנה בהתאמת הסל לפריטים שנשלחו בעת יצירה. [סקירת המערכת](ARCHITECTURE_REVIEW_2026-11-18.md) כוללת עדכון למצב זה. נדרש ליישר את תיעוד ה־Checkout לאחר מעבר על מלוא התהליך.
- [Backend תפעול](BACKEND_OPERATIONS.md) מסומן כמפרט יעד, אך פסקת גישה להזמנה אומרת שאין API לצפייה; בנתיב הקיים `GET /orders/confirmation` יש אישור פרטי מוגבל באמצעות אסימון. יש לעדכן את הפסקה תוך שימור מדיניות והחלטות שעדיין רלוונטיות.
- יש להמשיך סקירת תוכן יסודית של שאר מסמכי ה־API, הסכמה, ההפעלה, התוכניות, דוחות הבדיקה ותצוגות HTML על מול הקוד והחלטות עדכניות. סטטוס DB, שירותים חיצוניים ודפדפן לא אומת בסבב זה. אין לקבוע שכל התיעוד מדויק מתוך בדיקת קישורים.

## אימות

יש להריץ `scripts/check-docs.ps1` לאחר כל שינוי באינדקס, במיקום מסמך או בקישור. הבדיקה מקומית ואינה מאמתת כתובות HTTP, עוגני כותרות או נכונות עובדתית. בדיקות קוד ומיגרציות אינן חלק מהסבב הזה.
