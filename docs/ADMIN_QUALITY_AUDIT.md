# אימות איכות והרשאות בניהול

[אינדקס](PLAN_INDEX.md) · [תור העבודה](NEXT_PHASE_PLAN.md) · [אימות מסכים](ADMIN_VERIFICATION.md).

עודכן: 09.10.2026. הבדיקות במסמך מקומיות, ללא מסד וללא שינוי נתונים חיים.

## תיקונים שאומתו

- מסכי Dashboard, Orders הישנים ו־Production דורשים במפורש `operations_manager`. משלוחן, משתמש ללא תפקיד ומשתמש שאינו פעיל אינם מקבלים נתונים; התשובות מורשות מסומנות `no-store`.
- גם שינוי מלאי דורש מנהלת תפעול. גוף חסר, כמות שאינה מספר שלם בטוח או אפס וסיבה ריקה נדחים לפני קריאה לשירות. שגיאות תשתית ממשיכות למטפל המרכזי ואינן נחשפות כתשובת 400 עם SQL או פרטי חיבור.
- ספירת ההתראות בדשבורד מסוננת לפי `admin_user_id` של הזהות המאומתת. מזהה שמגיע בפרמטר בקשה אינו משמש לבחירת משתמש; ללא הקשר משתמש אין ספירה כללית.
- כניסה ויציאה מאפסות בחירת הזמנות, תאריכים, מסננים ועימוד הזמנות ומשימות. תאריכים מתאפסים רק בהחלפת Session, לפי שעון ישראל.
- תשובת API מנהלית שנשלפה תחת משתמש אחר נדחית, גם אם ההחלפה קרתה בזמן קריאת גוף JSON. אין להעביר נתונים ישנים ל־callbacks של הפעולה.
- ערכי תאריך שאינם תאריך לוח תקין אינם מחליפים את מצב המסך. דף דוח הייצור אינו שולח בקשה או מאפשר הדפסה עבור תאריך קישור פגום.
- מעבר מייצור להזמנות מסיר מסנני עיר וסטטוס סותרים, מאפס עמוד ובחירה ומחיל את תאריך הייצור והווריאציה. שינוי התאריך מסיר את הווריאציה הקודמת.

## ראיות מקומיות

- `npm test` בתיקיית `apps/admin-mobile`: חמש בדיקות ללא דפדפן או DB: תאריכי לוח, מעבר ייצור להזמנות, מניעת תאריך פגום, בידוד UI בין Session-ים ודחיית תשובה ישנה.
- `npm run typecheck` בתיקיות Admin ו־API עבר.
- 23 בדיקות API ממוקדות עברו: בקר Dashboard, בקר שינוי מלאי, בקר עימוד הזמנות, שירות Dashboard ו־Postgres Dashboard עם לקוח SQL מדומה.
- בדיקת HTTP הקיימת לשינוי מלאי עודכנה עם תפקיד מנהלת מפורש. הרצה חיה שלה אינה חלק מראיות סבב זה.
- לא הופעלו מיגרציות, לא נשמרו הגדרות ולא נוצרו או שונו הזמנות במסגרת הבדיקות.

## עבודה שאינה תלויה בתהליך ההזמנה המושהה

- אפשר להשלים במקביל ניהול קטלוג/תמונות, תוויות אריזה ורשימות אספקה, תיבת התראות מקומית והעדפות משתמש, וזרימות משימות מערכת לפי המפרט.
- חיבור Push דורש אימות הדפדפן והתשתית הרלוונטית; עצם הצגת התראות אינה מוכיחה מסירה למכשיר.
- בדיקת שמירת הגדרות ושינוי סטטוסים מול Production דורשת אישור לשינוי נתונים ונתוני בדיקה מתאימים. בדיקות עם mocks אינן אימות DB.
- אפשר לבדוק PDF מרובה עמודים ועברית בעזרת נתונים מאושרים או דוגמאות מקומיות; רשימה ריקה ופתיחת חלון הדפסה אינן הוכחה של תוצר מלא.

## תלוי בהחלטות או בתהליך ההזמנה

- אין ליצור הזמנות, לחבר checkout או לבצע תשלום בזמן ההשהיה שביקשה בעלת האתר.
- שינוי תאריך, ביטול, החזר וחשבונית תלויים בכללים המתועדים ובהכרעות שנותרו פתוחות; אין לנחש כללים כדי לסיים מסך.
- אימות מסלול לקוחה מלא, תשלום וחשבונית ממתין לחידוש התהליך ולספקים הנדרשים.
