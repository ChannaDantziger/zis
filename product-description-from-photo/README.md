# תיאור מוצר מתוך תמונה

Skill נפרד לכתיבת תיאור מוצר על בסיס תמונה ופרטים מאומתים. הוא אינו מעבד תמונות; הוא עוזר להבין מה אפשר לתאר, מבקש את שם המוצר ומברר פרטים חסרים, ואז מנסח טקסט פשוט, ברור ומגרה בלי שפה מקצועית או פרסומית.

## הפעלה

צרפי תמונה והפעילי `$product-description-from-photo`. אפשר לבקש, למשל: "כתבי תיאור קצר למוצר שבתמונה".

אם שם המוצר לא נמסר, הסקיל ישאל מה שמו לפני כתיבת תיאור סופי. לפי הצורך הוא יברר סוג ציפוי ומילוי, מרכיבים, כמות, גודל ומידות מדויקות כמו קוטר, רדיוס וגובה. הוא לא ינחש מרכיבים, טעמים או מידות על סמך התמונה בלבד.

## אופי התיאור

הניסוח צריך להסביר במילים יומיומיות מה יש במוצר ואיך הוא נראה או בנוי. הוא יכול להיות חמים ומגרה, אבל נשאר ענייני: בלי הבטחות, מילים מפונפנות או טענות על מרכיבים ותכונות שלא אושרו.
